# 📊 AchieveX – Student Achievement Dashboard

A full-stack web application built using **Flask (Python)** and **MySQL** that manages student achievements while **visually demonstrating real-time SQL query execution**.

This project is designed as both:
- ✅ A **management system** for student achievements  
- ✅ A **learning tool** to understand how SQL queries work behind the scenes  

---

## 🚀 Features

### 👨‍🎓 Student Management
- Add and manage student records  
- Assign faculty advisors  
- Enforces relational integrity using foreign keys  

### 🏆 Achievement Tracking
- Record achievements for students  
- Categorize achievements (Technical, Academic, etc.)  
- Structured relational data handling  

### ✅ Verification Workflow
- Approve / Reject achievements  
- Simulates real-world faculty validation systems  

### ⚡ Live SQL Query Panel (Core Feature)
- Displays all executed SQL queries in real time:
  - `SELECT`
  - `INSERT`
  - `UPDATE`
  - `DELETE`
- Shows how frontend actions translate into backend SQL execution  
- Helps users understand DBMS concepts visually  

### 🔍 Filtering System
- Filter achievements by status:
  - Approved  
  - Pending  
  - Rejected  

---

## 🧠 Learning Focus

This project emphasizes **understanding SQL through interaction**:

- Demonstrates **JOIN operations** in real scenarios  
- Enforces **foreign key constraints**  
- Shows how **CRUD operations map to SQL queries**  
- Bridges the gap between **DBMS theory and implementation**
